# React Modal Plugin

A simple and reusable modal component for React applications.

## Description

`react-modal-plugin` is a reusable React component that allows you to easily
display a modal window in your application.

The modal provides:

- A centered modal window
- A semi-transparent overlay
- A close button
- Custom content through React children
- A callback to handle closing the modal

## Installation

The plugin is currently used as a local package.

From your React project, install the plugin with:

```bash
npm install ../../react-modal-plugin
